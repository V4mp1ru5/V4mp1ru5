## 🚀 Projects

### 🤟 Signify: an app for learning American Sign Language
A student research project built by a team for a university project course. The app recognises signs from a webcam, including fingerspelled letters and whole words. I built the machine-learning part and the recognition server, and my teammates built the Flutter app.

- Designed an **end-to-end machine-learning pipeline**: GPU pose estimation (RTMPose), hand-shape features and a recurrent network (GRU) with attention
- **Evaluated models carefully**: cross-validation on signers the model never saw during training, plus paired statistical tests to decide which changes to keep
- **Debugged training methodically**, including numerical instability and a recurrent readout that never learned
- **Sped up experiments** on the GPU with cuDNN-compatible augmentation and data preparation running on the CPU in parallel
- **Integrated** both recognisers into the team's Flutter app through a **Python HTTP server**

`Python` `TensorFlow/Keras` `NumPy` `OpenCV` `MediaPipe` `RTMPose` `ONNX Runtime` `TensorRT` `CUDA`

### 🎮 [Gragus Origins](https://github.com/4rn0d/Gragus-Origins)
A 2D action roguelike made in Unity as a team semester project.

- **Procedural dungeon generation** (room-type placement, connections)
- A **modular enemy AI** built from actions and conditions (patrolling, following the player)
- A **state-based combat system** (attack phases, damage, explosions, projectiles)
- **Physics interactions** (throwable objects, explosive barrels, collisions)
- A **component-oriented, data-oriented architecture** that makes new behaviours easy to add

`Unity` `C#` `Procedural generation` `State machines` `2D physics`
